# 测试与性能验证计划

当前仅为计划，尚无业务代码，**没有测试通过结果**。

## 测试层次

- 单元：价格规则、状态机、日期拆分、错误映射。
- PostgreSQL集成：Flyway、约束、MyBatis、事务回滚、触发器、过程/视图。
- API集成：认证、权限、DTO校验、幂等。
- 前端：核心组件和真实API联调。
- JMeter：并发抢订/容量/库存和查询性能。

## 并发方案

- 100线程抢最后一个住宿资源：成功1，冲突99，无有效重叠。
- 50线程抢20张票：成功数量总和20，`reserved_quantity=20`。
- 多线程租同一资产：成功1。
- 多线程租批量库存：成功数量总和不超过可用量，库存无负数。
- 在每次测试后直接SQL核对订单、占用、流水与计数，而非只看HTTP响应。

## 性能方案

- 生成至少50,000订单、100资源、365日规则/场次测试集。
- 测试空闲搜索、用户订单分页、价格日历、每日收入、缆车统计。
- 保存索引前后 `EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON)`；写操作放在可回滚事务或测试库。
- 报告实际执行时间、行数、扫描类型、缓冲命中；不只报告JMeter平均响应。
